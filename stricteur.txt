الترتيب الذي أقترحه
1. إدارة المنتجات (Products)
   - عرض جميع المنتجات في جدول.
   - البحث والتصفية حسب الحالة والتصنيف.
   - إضافة منتج جديد.
   - تعديل بيانات المنتج.
   - تفعيل المنتج وإيقافه.
   - إدارة الصور والمتغيرات والمخزون.
2. إدارة الطلبات (Orders)
   - عرض الطلبات والبحث عنها.
   - عرض تفاصيل الطلب والعميل.
   - تغيير حالة الطلب.
   - متابعة حالة التوصيل.
3. إدارة التوصيل (Delivery)
   - شركات التوصيل.
   - الولايات والبلديات.
   - مكاتب التوصيل.
   - أسعار التوصيل للمنزل والمكتب.
4. إدارة العملاء (Customers)
   - عرض العملاء.
   - سجل طلبات كل عميل.
   - معلومات التواصل والعناوين.
5. الإحصائيات والتقارير (Reports)
   - المبيعات والإيرادات.
   - أداء المنتجات.
   - الطلبات حسب الحالة.
   - أداء المتجر خلال فترات زمنية.
6. الإعدادات والمسؤولون (Settings & Admins)
   - إعدادات المتجر.
   - إدارة حسابات المسؤولين وصلاحياتهم.
   - تغيير كلمة المرور وإعدادات الحساب.
لنبدأ بإدارة المنتجات
أقترح أن ننفذها بهذا الترتيب:
1. ربط صفحة المنتجات الحالية بقاعدة البيانات.
2. إنشاء API لجلب المنتجات مع Pagination والبحث.
3. بناء جدول المنتجات في لوحة الإدارة.
4. إنشاء صفحة إضافة منتج.
5. إنشاء صفحة تعديل منتج.
6. إضافة إدارة المخزون والصور والمتغيرات.
